# Triage Labels

The default local vocabulary is used.

| Role | Label |
|---|---|
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not fix | `wontfix` |

New tickets are `ready-for-agent` unless a human review is required.
