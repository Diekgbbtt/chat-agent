# Project Submission

Please submit all required files using the following structure:

    Project Submission X/
    ├── main.py
    ├── requirements.txt
    ├── report.pdf
    ├── presentation.pdf
    └── additional_files/

## main.py

Your code for running the chatbot should be here.

Please do not rename this file, as we will use `main.py` to run your chatbot during the online evaluation.

Running `main.py` should start your chatbot server and make it ready to receive requests.

Please make sure that your code handles errors appropriately and that the server continues running without crashing during the evaluation.


**⚠️ IMPORTANT:** Make sure that all required packages are installed in the base Python environment (`/opt/conda/bin/python`) of your Nuvolos VS Code application, as this is the environment that will be used during the online evaluation.


## requirements.txt

Please list any additional Python packages required by your chatbot in a `requirements.txt` file.


## report.pdf

Please submit your project report as a PDF file.


## presentation.pdf

Please submit your presentation as a PDF file.


## additional_files/

If your project contains additional code files or modules, please place them in the `additional_files/` folder.

Please make sure that all paths and imports are configured correctly so that your chatbot can be successfully run from `main.py`.
