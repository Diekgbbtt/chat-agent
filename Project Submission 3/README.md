# Project Submission

Please submit all required files using the following structure:

    Project Submission X/
    ├── main.py OR main.ipynb
    ├── report.pdf
    ├── requirements.txt
    ├── presentation.pdf
    └── additional_files/

## main.py / main.ipynb

Please place your main project code in either `main.py` or `main.ipynb`.

Please make sure that your code can be successfully run from this file.


## requirements.txt

Please list any additional Python packages required by your project in a `requirements.txt` file.


## report.pdf

Please submit your project report as a PDF file.


## presentation.pdf

Please submit your presentation as a PDF file.


## additional_files/

If your project contains additional code files or modules, please place them in the `additional_files/` folder.

Please make sure that all paths and imports are configured correctly so that your project can be successfully run from `main.py` or `main.ipynb`.
